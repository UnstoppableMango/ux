# AGENTS.md

Guidance for coding agents working in this repository.

## Overview

ux is a language and toolset for composing converters into artifact conversion pipelines.
A converter turns one format into another; TDL backends are converters, and so is any other tool that converts between formats.
Lossy conversions must be visible to the user, and silenceable.

ux is written in Haskell and built with Nix.

## Commands

```shell
nix develop        # devShell: ghc, cabal, haskell-language-server, protoc, proto-lens-protoc
make build         # nix build .#
make test          # cabal test
make run           # cabal run ux --
make fmt           # nix fmt (treefmt: ormolu, cabal-fmt, nixfmt, actionlint)
make check         # nix flake check: the package with its tests, and formatting
make update        # nix flake update
make generate      # TDL's protos -> gen/
```

Dependencies come from nixpkgs' `haskellPackages`, so `cabal` in the devShell builds offline against the shell's GHC package set.
A dependency added to `ux.cabal` is picked up by `callCabal2nix` with no other change, as long as nixpkgs has it.

## Layout

- `flake.nix`: inputs, the devShell, treefmt, and the packages.
  `packages.ux` is the full Haskell package; `packages.default` is its executable alone, through `justStaticExecutables`.
- `nix/default.nix`: the package, built with `callCabal2nix`.
- `ux.cabal`: the library, the `ir` sub-library, the `ux` executable, and the `spec` test suite.
  The version lives here and reaches `ux version` through `Paths_ux`.
- `src/Ux/Syntax.hs`: the parse tree.
- `src/Ux/Parser.hs`: the megaparsec parser.
  The grammar is a placeholder: `pipeline name = a -> b -> c`, with `//` comments.
- `app/Main.hs`: the CLI entry point.
- `gen/`: proto-lens bindings for `tdl.ir.v1` and `tdl.plugin.v1`, exposed as `ux:ir`.
- `docs/design/`: designs. `language.md` explores the language itself; a design describes the target, not the implementation.
- `test/`: hspec. A new `Ux.FooSpec` module is listed in `test/Spec.hs` and `ux.cabal`; `hspec-discover` is avoided because cabal cannot find its executable offline.
- `cabal.project`: enables the test suite, so `cabal test` solves against the devShell's packages.

## Generated code

`gen/` is generated by `make generate` from TDL's protos and committed, as TDL commits its `.pb.go` files.
The devShell sets `TDL_PROTO` to the protos of the `tdl` flake input, so `nix flake update tdl && nix develop --command make generate` follows TDL.
`gen/` is excluded from treefmt.

TDL's protos are Editions 2024 with implicit presence; proto-lens reads them as proto3, and the wire format is the same.
